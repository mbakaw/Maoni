# Maoni OS

A soft computer desktop inspired by floating browser windows on a blue sky. Animated gradient layers drift behind translucent navigation and light grey window chrome. Windows and colourful sticky notes can be dragged on desktop. Phones use a stacked layout with a two-column note grid.

The main tabs are home, the conversations, the maoni wall, our maoni and the community. Our maoni contains the existing essays and sources. Events and the separate multiplayer game remain accessible from the header, desktop and Start menu.

Original event photographs remain unedited. Notes made with New sticky note are private to the current browser and stored locally. The shared Maoni Wall uses the existing D1 API and consent flow. Keyboard users can move a focused titlebar with arrow keys. Reduced-motion preferences disable background animation.
